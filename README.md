# InternCircle Task 6: Weather App

## Project Overview
A Python command-line application that fetches real-time weather information for a city using the OpenWeatherMap API.

## Features
- Fetches current weather data from a REST API
- Displays temperature and feels-like temperature in Celsius
- Shows humidity and weather conditions
- Parses JSON responses
- Handles invalid city names and network errors
- Supports repeated city searches

## Technologies Used
- Python
- Requests
- OpenWeatherMap API
- JSON

## Installation
Install the required library:

`python -m pip install requests`

## How to Run
1. Get an API key from OpenWeatherMap.
2. Add your API key to `main.py`.
3. Run `python main.py`.
4. Enter a city name to view its weather.

## Security
Keep your API key private. Do not upload personal API keys to public repositories.
